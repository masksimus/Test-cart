Добро пожаловать

Приложение «Карты Таро» — развлекательный сервис для гадания на картах Старших Арканов. Все предсказания носят развлекательный характер и не являются профессиональной консультацией.

Политика конфиденциальности

Какие данные мы используем. Идентификатор пользователя VK (только для отображения вашего имени на приветственном экране) и встроенное хранилище VK для сохранения карты дня и истории раскладов.

Передача третьим лицам. Ваши данные не передаются третьим лицам. Все данные хранятся в безопасном хранилище VK.

Реклама. Приложение бесплатное и поддерживается за счёт показов рекламы VK перед открытием раскладов. Никакой персональной информации рекламодателям не передаётся — рекламу обслуживает сама платформа VK.

Возраст. Приложение предназначено для пользователей старше 18 лет.

Развлекательный характер. Все предсказания и интерпретации карт носят исключительно развлекательный характер. Не принимайте важных жизненных решений на их основе.

О приложении

«Карты Таро» — бесплатное развлекательное приложение для ежедневных предсказаний по Старшим Арканам. Все толкования носят развлекательный характер. Приложение поддерживается за счёт коротких рекламных видео перед открытием раскладов.

Получайте пуш-уведомление каждый день, чтобы не пропустить свою Карту Дня и вовремя заглядывать в будущее.
